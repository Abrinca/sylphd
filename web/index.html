sylphd

Find the closest GTDB genomes to a bacterial or archaeal assembly using sylph k-mer ANI. Docs.

Privacy: your sequence is sent to the server for sketching and is not stored or logged. Only sizes, timings and request outcomes are recorded.

Terms: free for academic use via this web page. For other uses (including programmatic/API access or commercial use), please contact us first: https://abrinca.com/contact. See the terms of use.
