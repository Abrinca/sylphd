# Example genome

`mycoplasma_genitalium_G37.fna.gz` is the *Mycoplasmoides (Mycoplasma) genitalium*
G37 reference genome, NCBI RefSeq assembly
[GCF_000027325.1](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_000027325.1/)
(`NC_000908.2`, 580,076 bp), downloaded from NCBI Datasets and gzip-compressed
unchanged. NCBI data is in the public domain.

It is itself part of GTDB, so the best hit is the genome itself (ANI 100%).
